💬 sl-messaging

Standalone Messaging Component

Features

  • ✨ Zero dependencies - works standalone
  • 💬 Real-time text messaging interface
  • 📹 Video call UI (demo mode)
  • 👥 Conversation management
  • 🎨 iOS-inspired design
  • 📱 Fully responsive

Usage

Simply include the component in your HTML:

<!-- Include the built component script -->
<script src="path/to/sl-messaging-bundle.js"></script>

<!-- Use the component -->
<sl-messaging 
  embedId="my-messaging" 
  sessionId="optional-session-id"
  enableVideo="true"
  enableAudio="true">
</sl-messaging>

Attributes

embedId      - Unique identifier for this instance
sessionId    - Optional session ID to join
enableVideo  - Enable video features ("true"/"false")
enableAudio  - Enable audio features ("true"/"false")
