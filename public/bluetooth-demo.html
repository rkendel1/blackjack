🔵 Bluetooth Web Component

A reusable Bluetooth embed component that can connect to Bluetooth devices. Built with Svelte 4 and the Web Bluetooth API.

⚠️ Note: This component requires a browser that supports the Web Bluetooth API (Chrome, Edge, Opera on desktop/Android). HTTPS or localhost is required. Click "Add New Device" to scan for nearby Bluetooth devices.

📖 Usage

Basic Usage:

<sl-bluetooth
    embedId="demo-bluetooth"
    deviceName="My Device"
    autoScan="false"
    persistDevices="true"
    theme="light"
></sl-bluetooth>

Attributes:

  • embedId - Unique identifier for the component
  • deviceName - Display name for this device
  • autoScan - Automatically scan on mount (true/false)
  • persistDevices - Remember paired devices (true/false)
  • theme - UI theme (light/dark)

Events:

  • ready - Component is ready
  • deviceconnected - Device connected
  • devicedisconnected - Device disconnected
  • error - Error occurred
